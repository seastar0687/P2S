# Good Example

## Context

A paper introduces a method that improves accuracy on a benchmark, but only tests a limited set of tasks.

## Script

This paper asks a narrow but useful question.

Can a model learn better representations before the final prediction step?

The authors test a two-stage method.

First, the model learns structure from the input data.

Then, it uses that structure for the downstream task.

On the reported benchmarks, this improves the average score.

But the paper does not show whether the method works outside these datasets.

So the result is promising, not final.

## Why This Is Good

- The hook is a paper-supported question.
- The result is bounded by the tested benchmarks.
- The final sentence avoids overclaiming.
